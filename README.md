## Main Features Covered

- Create a task with title, description, priority, and due date
- View all tasks in a searchable and filterable list
- Open a task detail view
- Mark open tasks as completed
- Edit task fields by id
- Soft delete tasks by id with confirmation
- View task summary counts for all, open, and completed
- Validate data on both frontend and backend
- Use rich-text descriptions in create, edit, and view flows
